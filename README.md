<sub>The profile changes every hour: the rice terraces, then the Old Quarter, then the page on its own. This hour shows the Old Quarter.</sub>

<p align="center"><img src="street/street.svg" width="100%" alt="Phố Commit, an illustrated street in Hanoi&#x27;s Old Quarter at dusk: tube houses named after my most active public repositories, motorbikes carrying my latest merged pull requests, and a phở cart serving my latest Substack post"/></p>

Phố Commit is a street in Hanoi's Old Quarter that grows with my GitHub activity: 4,349 contributions in the last year. Each tube house is one of my repos, and the busier I am in it, the taller it gets: `quickdbd-cli` is 6 floors after 207 commits this year. I haven't merged a pull request yet this year, so the road is quiet for now. The phở cart is serving my latest post from The Analytics Engineer's Handbook, [I let a coding agent build my dashboard. I didn't let it touch the math.](https://markphammm.substack.com/p/i-let-a-coding-agent-build-my-dashboard), and is waiting for its first order. Nobody has parked here this month yet, so the best spot on the sidewalk is yours. The sky follows the time in Hanoi, where it's dusk right now.

<p align="center"><sub>Buttons open a pre-filled issue. Hit Create and the street updates in about a minute.</sub></p>

<details>
<summary>How Phố Commit works</summary>

- **Houses** are my 8 public repositories with the most commits this calendar year, from the GitHub GraphQL API. The red sign is the repo name and the blue house number is its commit count.
- **Floors** go up at 10, 25, 50, 100 and 200 commits, so a quiet repo still gets a one-storey house and the busiest ones top out at six.
- **Motorbikes** on the road are my most recently merged pull requests in public repos this year, with the PR number on the plate.
- **The phở cart** serves the newest post from The Analytics Engineer's Handbook, read from its RSS feed. Every "Order phở" issue adds a bowl to the counter.
- **Parked bikes** belong to visitors who opened a "Park a motorbike" issue in the last 30 days. Everyone gets one visit per day, Hanoi time.
- **The sky** follows the time in Hanoi: dawn, day, dusk or night. After dark the windows and lanterns light up.
- **No server.** A GitHub Action redraws the street four times a day and right after each visit, then commits one SVG to this repo. The code is in [`street/`](street).

</details>
